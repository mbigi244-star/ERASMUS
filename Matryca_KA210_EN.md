# KA210 LogFrame Matrix Reference Structure

## Overview

This document serves as the reference structure for generating KA210 Small-scale Partnership applications. All prompts should reference this matrix to ensure logical consistency.

## Logic Flow

```
PROBLEM → OBJECTIVE → ACTIVITY → OUTPUT → RESULT → KPI
   ↓           ↓           ↓          ↓         ↓        ↓
What hurts? → What we    → What we   → What we  → What   → How we
              want to      will do     create    changes   measure
              achieve
```

## SMART Objectives Checklist

Each objective MUST be:

- **S**pecific: Clearly defined, no ambiguity
- **M**easurable: Quantifiable with numbers
- **A**chievable: Realistic within project scope
- **R**elevant: Connected to priority and needs
- **T**ime-bound: Has deadline within project duration

### Good Examples:
- "Train 60 youth in AI literacy within 18 months"
- "Create digital toolkit in 3 languages by month 12"
- "Increase digital competence scores by 30% (pre/post test)"

### Bad Examples:
- "Improve digital skills" (not measurable)
- "Help young people" (not specific)
- "Build capacity" (vague)

## Evidence Requirements

For each claim, provide:

1. **Source**: URL or document reference
2. **Quote/Number**: Exact data point
3. **Access Date**: When retrieved
4. **Matrix Element**: Which objective/output it supports
5. **Form Section**: Where it will be used

### Evidence Categories:

- **Eurostat data**: EU-level statistics
- **National reports**: Country-specific data
- **Organization data**: Own research, program statistics
- **Micro-research**: Surveys with N≥10 from target groups
